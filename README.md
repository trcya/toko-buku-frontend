# 🖥️ Toko Buku Client (Frontend)

Antarmuka pengguna untuk aplikasi Toko Buku. Dibuat dengan performa tinggi tanpa framework berat.

## 🛠️ Teknologi
- **HTML5 & Tailwind CSS**: Struktur dan desain UI responsif.
- **Vanilla JavaScript**: Logika aplikasi dan manipulasi DOM.
- **Fetch API**: Berkomunikasi dengan Backend API secara asinkron.



## 💡 Fitur
- **CRUD Interaction**: Form tambah buku, tombol edit dengan prompt, dan konfirmasi hapus.
- **Dynamic Updates**: Tabel diperbarui secara otomatis tanpa refresh halaman (SPA-like).
- **Responsive Design**: Tampilan rapi di berbagai ukuran layar berkat Tailwind.

## 🚀 Cara Menjalankan
1. Clone repo: `git clone <url-repo-frontend>`
2. Pastikan **Backend API** sudah berjalan di `http://localhost:3000`.
3. Buka `index.html` menggunakan **Live Server** di VS Code.
